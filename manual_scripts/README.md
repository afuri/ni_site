# Ручные административные сценарии

В этом каталоге собраны сценарии, которые запускаются оператором вручную для диагностики, импорта, выгрузки, переоценки результатов и загрузки файлов в MinIO. Они не запускаются автоматически вместе с приложением.

Все команды следует выполнять из корня проекта:

```bash
cd /Users/alexfedosov/Documents/ni_site_v2
```

Перед сценарием, меняющим данные, сначала используйте режим `DRY_RUN=1` или `--dry-run`, если он предусмотрен. Сценарии предполагают, что Docker-сервисы проекта уже запущены.

## Диагностика и отчёты

- `attempt_forensics.sh` — подробная проверка попытки пользователя.
- `find_instant_submit_cases.sh` — поиск подозрительно быстрых отправок.
- `export_attempts_summary_from_list.sh` — выгрузка сводки по списку попыток.
- `export_attempts_summary_no_teachers_from_list.sh` — сводка без данных учителей.
- `monitor.sh` — ручной сбор серверных метрик.

## Изменение и импорт данных

- `bulk_update_user_geo.sh` — массовое обновление географии пользователей.
- `import_final_round_attempts.sh` — импорт результатов очного этапа.
- `promote_student_grades.sh` — ежегодный перевод учеников на один класс вверх с dry-run, аудитом и защитой от повторного запуска.
- `import_school_directory.sh` — транзакционный импорт Region → City → School и перенос пользователей; dry-run используется по умолчанию, целевой каталог обязан быть пустым, повторный `batch_id` запрещён.
- `replace_school_no_with_number_sign.sh` — заменяет литеральное `No` на `№` в кратких и полных названиях и адресах канонических школ; пересчитывает нормализованные поля поиска, по умолчанию выполняет dry-run.
- `verify_school_directory.sql` — read-only контроль количеств, FK и согласованности статусов после импорта. Production-порядок и ожидаемые значения описаны в `../PRODUCTION_SCHOOL_MIGRATION.md`.
- `regrade_task37_words.sh` — переоценка ответов для задания 37.
- `regrade_task50_51_words.sh` — переоценка выбранных текстовых заданий.
- `regrade_task_units_3class.sh` — переоценка ответов с единицами измерения.

## Загрузка файлов

- `upload_diplomas_minio.py` — загрузка дипломов в MinIO.
- `upload_teacher_certificates_minio.py` — загрузка сертификатов учителей в MinIO.

Каталог `backend/scripts` намеренно остаётся внутри backend: его штатные скрипты включаются в production Docker-образ и используются для обслуживания приложения.
