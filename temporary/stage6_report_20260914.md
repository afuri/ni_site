Известные некритичные предупреждения: deprecation warnings зависимостей,
предупреждения будущих флагов React Router и сообщение Redis teardown после
успешного завершения pytest (`Event loop is closed`).

В исходном CSV найдены 4 школы, у которых `short_name` буквально совпадает с
`address`. Импортёр корректно сохранил исходные значения; это отдельный вопрос
качества справочника, а не ошибка миграции.

После перезапуска Docker Desktop обнаружена локальная проблема containerd:
Compose не может разрешить свежескачанный тег `postgres:16`, хотя список образов
его показывает. Сохранённый контейнер PostgreSQL запускается и работает; перед
следующим пересозданием контейнеров требуется перезапустить/починить хранилище
образов Docker Desktop. Тома PostgreSQL не удалялись.
