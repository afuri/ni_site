# Manrope для личного кабинета

Файлы извлечены без изменений из ресурсов согласованного образца
`temporary/platform_page_design/стр1.webarchive`.

- `manrope-cyrillic.woff2` — кириллица, включая знак №.
- `manrope-latin.woff2` — латиница и основная пунктуация.

Исходные ресурсы Google Fonts: Manrope v20, `xn7gYHE41ni1AdIRggOxSvfedN62Zw.woff2`
и `xn7gYHE41ni1AdIRggexSvfedN4.woff2`.
Локальное имя CSS `Manrope Platform` изолирует подключение кабинета от общей темы сайта.
