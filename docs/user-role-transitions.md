# Переходы ролей

- Дошкольник — `student` с классом 0. Для перехода в школьники нужно передать класс 1–11 и ID существующей активной школы своего региона. «Школа отсутствует» не подходит. Правило действует в админке, собственном профиле и при редактировании ученика учителем.
- Прямой переход дошкольника в другую роль запрещён. После перевода в школьники применяется обычная механика смены роли.
- Школьник → учитель: только админский API; требуется явно заполненный предмет кириллицей с заглавной буквы. Класс и ручной список учителей очищаются.
- Учитель → школьник: только админский API; требуется явно указанный класс 1–11. Предмет, флаг модератора и запрос модерации очищаются.
- При смене роли должна быть выбрана активная школа в активном регионе/городе. Текущая школа переиспользуется и проверяется; можно указать другую школу и регион в том же запросе.
- Несовместимые связи `teacher_students` удаляются вместе с изменением роли. ID аккаунта, общие поля, coins и результаты олимпиад не удаляются.
- Проверки школьного профиля учитывают итоговую роль, а не старую. Проверки прав на запросах используют актуальную роль из БД; при смене роли отзываются refresh-токены. Действие записывается в аудит.

Форма админки показывает нужное поле по выбранной роли и поясняет ошибки API.
Изменения требуют обновления API, frontend админки и основного frontend. Миграций БД нет.
