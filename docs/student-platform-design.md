# Дизайн личного кабинета ученика

Основа — три webarchive из `temporary/platform_page_design`. Перенесены локальные
шрифты Manrope (кириллица и латиница), SVG-иконки, размеры оболочки, карточки,
оформление профиля и адаптивная навигация. Кот — существующий `src/assets/cat.png`.

## Согласованный состав

- Главная, результаты и дипломы, профиль; уведомления доступны через колокольчик.
- Отдельного раздела «Олимпиады» нет; начать и продолжить участие можно с главной.
- «Мой сезон» показывает участия текущего учебного года; в результатах доступен
  выбор сезона и вариант «Все сезоны».
- Прогресс достижений, награды и уровень пользователя отсутствуют.
- Coins оформлены, но скрыты по умолчанию: `VITE_ENABLE_PLATFORM_COINS=false`.
  Баланс берётся из `user.coins`; механика начислений не добавлялась.
- «Помощь» ведёт на `/docs/instruction.pdf`, «О платформе» — на `/#about`.
- Профиль сохраняет действующую модель региона, школы, заявок и дошкольников,
  связи с учителями и проверку email. Правила доступа к дипломам сохранены.

## Сезоны и совместимость API

Сезон начинается 1 сентября в 00:00 по `Europe/Moscow` и заканчивается перед
началом следующего сентября. Принадлежность определяется по `available_from`
олимпиады, а не по дате выставления результата.

`GET /attempts/results/my` и `GET /attempts/{id}/result` возвращают дополнительное
поле `olympiad_available_from`. Оно получено из уже загруженной олимпиады, без
дополнительного запроса для каждой строки. Схема БД не менялась, миграция не нужна.

Если frontend работает со старым API, работы доступны в «Все сезоны» и «Без даты
сезона»; дата не подменяется датой оценки. Для корректного блока текущего сезона
необходимо развернуть обновлённый API вместе с frontend.

## Проверка и развёртывание

Собрать основной frontend: `cd frontend && npm run build:app`. Обновить API
обычным для выбранного окружения способом (пересборка его контейнера). Сохранить
флаг coins выключенным. Дополнительная загрузка справочника школ не требуется.

Проверить на desktop и мобильном экране:

1. Главная: пустое состояние, активная попытка, отправленная работа и опубликованный результат.
2. Выбор предмета, подтверждение старта, продолжение попытки.
3. Сезоны, просмотр своей работы, доступность диплома согласно статусу школы.
4. Профиль: сохранение и отмена, смена региона и школы, дошкольник, заявка на школу.
5. Модальное окно заявки прокручивается и не закрывается по клику вне окна.
6. Уведомления, связи с учителями, ссылки помощи и выхода на мобильном экране.

Автотесты сезонов проверяют границу 1 сентября по Москве и позднюю публикацию.
API-тест проверяет одинаковую дату олимпиады в одиночном результате и списке.
