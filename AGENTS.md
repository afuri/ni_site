# Инструкции агентам — NI_SITE v2

Эти правила обязательны для всех AI-агентов, работающих с данным репозиторием. Дополнительные правила проекта находятся в `codex.md`.

## Обязательная Git-политика

1. Работать разрешено только в ветке `codex/v2-development`.
2. Перед изменением файлов проверить ветку командой `git branch --show-current`.
3. Если текущая ветка отличается, остановиться и сообщить пользователю. Не переключать ветку автоматически.
4. Не выполнять автоматически `git pull`, `git fetch`, `git push` и эквивалентные сетевые Git-операции.
5. Не создавать, не обновлять и не объединять GitHub Pull Request автоматически.
6. Не переключаться на `main`, не коммитить в `main`, не выполнять merge, rebase или cherry-pick в `main` и не отправлять изменения в `main`.
7. Pull/fetch, push, создание Pull Request и интеграционные операции разрешены только по отдельному явному указанию пользователя в текущей задаче с точным названием операции и ветки.
8. Общая просьба завершить задачу, опубликовать результат или продолжать автономно не является разрешением на эти операции.

Локальное чтение Git-истории, просмотр статуса и создание изменений в разрешённой ветке допустимы в рамках задачи. Коммиты создаются только по явной просьбе пользователя.

## Проектные правила

Перед работой прочитать и соблюдать `codex.md`. При конфликте правил применяется более строгий запрет на изменение или публикацию Git-состояния.
